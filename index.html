Findings

Three ways the filters mislead you

Measured in a live logged-in session, August 2026. Counts drift; the behaviour is the point.

1

A country name resolves to the wrong country

location=Armenia matches Armenia, Quindío, Colombia and returns 1,385 Latin American results. The reasonable conclusion is that no work exists for you, so you stop looking. The correct id returns 83 genuine Armenia-remote roles.

2

The Contract job type deletes almost everything real

Filtering job type to Contract against one country returned 1 result. The same search unfiltered returned 83. Companies hiring international contractors still tag the posting Full-time — the arrangement lives in the contract, not that field. That is why there is no Contract filter above.

3

"Remote" means remote within that one country

A worldwide remote search returns "Mexico (Remote)", "India (Remote)", "United States (Remote)" — each still expecting local work authorization. Remote is not the same as globally hireable, and no filter expresses the difference.
